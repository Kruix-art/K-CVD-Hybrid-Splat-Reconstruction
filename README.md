Installation
Requirements
Python 3.10 or newer
OpenCV (cv2)
NumPy
Kivy
Desktop Setup

Install the required dependencies:

pip install opencv-python numpy kivy

HOW TO RUN THE APPILCATION


Android Setup (Pydroid 3)
Install the following from the Play Store:
Pydroid 3
Pydroid Repository Plugin
OpenCV Plugin for Pydroid
Install dependencies in the Pydroid terminal:
pip install numpy kivy
Grant required permissions:
Camera
Storage
Place the script in:
/storage/emulated/0/Python Projects/
Run the script from within Pydroid
Output Directory

The application will create the following directory automatically:

/storage/emulated/0/Python Projects/scans/

Generated files:

last_splat_cloud.json — saved point cloud data
camera_calibration.json — camera calibration data
